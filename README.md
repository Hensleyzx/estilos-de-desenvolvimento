# Estilos de Desenvolvimento de Software

Projeto escolar com exemplos funcionais de diferentes estilos de desenvolvimento de software.

## Integrantes

- Davi Hensley De Araujo Costa
- Kaio Jerry
- Cristian Davi
- Mickael Medeiros Rodrigues

## Exemplos

1. High-Code — controle de notas.
2. Low-Code — central de chamados baseada em configuração.
3. No-Code — construtor visual de formulários.
4. Vibe Coding — sistema de chamada escolar criado a partir de prompt.
5. Programação assistida por IA — calculadora de orçamento com apoio de IA.
6. Programação visual — quiz montado com blocos.
7. Pro-Code — controle de estoque com validações e testes.

A página principal do projeto é `index.html`. O relatório em PDF também está incluído no repositório.

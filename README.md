## Estrutura dos exemplos

O **High-Code é o foco principal** e por isso recebeu um sistema acadêmico mais completo, com cadastro, edição, exclusão, busca, cálculo de média, classificação, indicadores e armazenamento local.

Os demais estilos usam exemplos mínimos, no estilo “Hello World”, apenas para mostrar a ideia central de cada abordagem:

1. **High-Code** — sistema acadêmico completo.
2. **Low-Code** — automação simples por prioridade.
3. **No-Code** — escolha e montagem de componentes visuais.
4. **Vibe Coding** — geração simples a partir de um prompt.
5. **Programação assistida por IA** — explicação de um pequeno trecho de código.
6. **Programação Visual** — sequência de blocos que gera “Olá Mundo”.
7. **Pro-Code** — regra simples de validação escrita diretamente pelo programador.

A página principal é `index.html`.

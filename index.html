Estilos de Desenvolvimento de Software

Exemplos simples e funcionais para demonstrar High-Code, Low-Code, No-Code, Vibe Coding, programação assistida por IA, programação visual e Pro-Code.

Alunos: Davi Hensley De Araujo Costa, Kaio Jerry, Cristian Davi e Mickael Medeiros Rodrigues.

Como testar: clique em um estilo abaixo, use o software e observe a explicação de por que o exemplo representa aquela abordagem. O foco principal do trabalho é o High-Code.

High-Code — Controle de Notas

Cadastro de alunos, cálculo de média e situação escolar.

Por que é High-Code? A interface, as regras de média, validações, armazenamento e atualização da tabela foram programados diretamente em HTML, CSS e JavaScript. O desenvolvedor controla cada regra do sistema.

Low-Code — Central de Chamados

Cadastro de chamados com uma automação de prazo de atendimento (SLA).

Por que representa Low-Code? O exemplo simula uma plataforma em que a tela é montada a partir de campos e regras previamente definidos. O usuário trabalha com componentes prontos, mas ainda existe lógica personalizada para a automação.

No-Code — Construtor de Formulário

Monte um formulário adicionando campos visualmente.

Por que representa No-Code? Quem usa o construtor não precisa escrever código para montar o formulário: escolhe o tipo de campo, informa o nome e o componente aparece pronto.

Vibe Coding — Chamada Escolar

Exemplo de sistema criado a partir de uma descrição em linguagem natural.

Por que representa Vibe Coding? O ponto de partida é o pedido: “Crie um sistema simples de chamada escolar que permita adicionar alunos e marcar presença ou falta”. A IA pode gerar grande parte do código a partir desse prompt, enquanto a pessoa testa e pede ajustes.

Pro-Code — Controle de Estoque

Cadastro, busca, validação e indicadores de estoque.

Por que é Pro-Code? Assim como High-Code, o sistema é desenvolvido com programação tradicional. Aqui o exemplo enfatiza organização de regras, validação dos dados, busca e indicadores, práticas comuns em projetos profissionais.
